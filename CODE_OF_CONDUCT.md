# Code de conduite

## Notre engagement

Ce projet est un espace de travail technique. Les contributions, les revues et
les discussions doivent rester **respectueuses et centrées sur le code**,
indépendamment de l'expérience, de l'origine, du genre, de l'identité ou du
niveau de chacun.

## Comportements attendus

- Critiquer une idée, un choix technique ou un diff — jamais une personne.
- Formuler les désaccords avec un argument vérifiable (comportement observé,
  référence, test qui échoue).
- Accepter qu'une décision soit tranchée et documentée dans un ADR plutôt que
  rejouée indéfiniment.
- Signaler les problèmes de sécurité **en privé** (voir [SECURITY.md](SECURITY.md)),
  jamais dans une issue publique.

## Comportements inacceptables

- Propos méprisants, harcèlement, attaques personnelles, contenu discriminatoire.
- Publication d'informations privées (données personnelles, secrets, identifiants)
  sans autorisation.
- Contributions délibérément malveillantes ou trompeuses.

## Application

Un manquement peut être signalé via les **avis de sécurité GitHub** du dépôt ou
en contactant le mainteneur ([@JordiBrisbois](https://github.com/JordiBrisbois)).
Les signalements sont traités de manière confidentielle. Selon la gravité, la
réponse va d'un rappel à la fermeture de la contribution, voire au blocage du
compte pour les cas répétés.

## Périmètre

Ce code s'applique aux espaces du projet : issues, pull requests, revues,
discussions et tout espace où quelqu'un représente le projet.
